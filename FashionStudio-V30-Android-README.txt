Fashion Studio V30 · Android 手机试玩包

安装：
1. 将 FashionStudio-V30-1080x1920.apk 传到 Android 手机。
2. 点击 APK 安装；如果系统提示，允许本次安装来自文件管理器的应用。
3. 打开“时光街区”，保持竖屏使用。

版本：V0.37
画布方向：竖屏，按 1080×1920 设计并适配手机 CSS 视口
包名：com.fashionstudio.demo
最低 Android：Android 6.0（API 23）

这是离线试玩包，页面和资源已内置，不需要电脑、局域网或网络服务。
登录、签到、社区大厅、聊天、表情、服装分享、排行榜解锁和市集解锁均为本地试玩逻辑。
试玩数据保存在应用 WebView 的本地存储中。
