# Fashion Studio · 时光百货

基于 2026-10-01 的现有设计方案与手机试玩，补齐主地图、商店、时装评比赛、服装图鉴，并替换为原创复古百货美术。新版日期：2026-10-08。

## 直接体验

- **单文件版：** 双击同目录下的 `fashion-studio-demo-v2.html`，即可离线游玩，无需安装。
- **源码版：** 双击 `index.html`，保留 `assets`、`styles.css`、`core.js`、`app.js` 的目录关系。
- **本机预览：** 已启动时可访问 `http://127.0.0.1:8128`。
- 适配桌面、平板和手机；手机底部有五个常驻导航入口。

## 建议的体验顺序

1. 主地图点击“改造”，完成橱窗的小心愿。
2. 工作台把 1 件 T 恤放到 9 件那摞上，观察升阶，再交付顾客订单。
3. 商店领取每日心意、补充体力，购买一件服装或装饰设计。
4. 图鉴点击已发现的服饰，领取首次发现奖励。
5. 评比赛选择三部位搭配，提交评比，领取里程碑。
6. 点击头像或地图右上设置，可导出/导入存档、重开、高级体验。

## 试玩与正式设计的区别

- 初始为 **LV12 体验存档**，1280 金币、80 钻石、68/100 体力，1F/2F 已开放，三条生成链可体验。
- 评比赛提前开放；正式设计仍保留 LV25 的成长门槛。
- 生成器 40% 产出 2 阶、25% 产出双件，沿用原试玩的加速参数。
- 高级体验经二次确认后提升到 LV32 并增加 7000 演示金币；不会自动点亮楼层或领取奖励。
- 本地存档只属于当前浏览器与访问地址。单文件版、源码版、本机预览可能使用不同存储空间，可通过导入/导出迁移。
- 不接真实支付、广告、云存档、联网排行或运营活动。排行明确为本地预设角色榜。
- 图鉴与舞台复用原创服饰图标；舞台展示服装组合，不是人物换装或骨骼动画。
- 装修以区域色调、设计状态和方案切换验证功能；正式版逐区域装修差分插画仍需制作。

## 交付内容

- `index.html`、`styles.css`、`app.js`：页面、适配和交互。
- `core.js`：独立的资源、棋盘、订单、商店、图鉴、装修、评比规则。
- `assets/`：原创六层百货场景、18 件服饰图标、设计师立绘、站点图标。
- `design/美术与四大系统补充方案.md`：系统规格、美术标准、设计冲突处理与后续边界。
- `tests/core.test.js`：29 项规则检查。
- `tests/browser.test.js`：五页、手机布局、点击/拖拽、购买、评分、奖励和存档检查。
- `tests/offline.test.js`：离线图片、真实触屏合并、装修应用、六层开放与确认安全检查。
- `tests/screenshots/`：桌面和手机预览截图。
- `build-standalone.js`：可重复生成离线单文件试玩。

## 开发者使用

无需项目依赖。安装 Node.js 后，可执行 `node server.js` 启动预览；`node --test tests/core.test.js` 执行规则检查；`node build-standalone.js` 生成单文件版。

浏览器检查使用 Playwright，需要电脑已安装对应的测试工具和浏览器。本项目没有下载或安装新依赖。
