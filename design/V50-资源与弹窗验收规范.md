# V50 资源与弹窗验收规范

本次修复保留 V48、V49，生成独立的 V50。经营、工作台、订单、换装与原有存档键保持兼容。

## 资源与安装包

- 浏览器、离线文件、Android WebView 共用同一目录结构：入口 HTML、运行 JS、样式 CSS、`assets/`。
- 禁止根据运行平台另行切换图片相对目录；CSS 背景、人物图集、服装、视频、音频使用同一规则。
- Windows aapt2 可能将嵌套资源写为反斜杠 ZIP 路径。必须在 zipalign 和签名前规范化为正斜杠；签名后不得修改 APK。
- 签名后检查每个资源路径、长度和 SHA-256；从最终签名 APK 提取网页文件进行回归，不能仅测试工程目录。
- 视频与音频在 APK 中保持未压缩，支持本地读取；HTTP 预览提供正确 MIME 和视频 Range 响应。
- 网页版必须连同 JS、CSS 和素材目录一起交付完整 ZIP，不单独交付 HTML。

## 启动阶段

- 首屏 Logo、圆形进度、活动指示动画只依赖内联代码和样式；大样式表及运行脚本不得阻塞首屏提示。
- 加载进度绑定资源读取；运行脚本、样式、关键场景读取完成后才能结束启动层。慢网仍保持活动动画。
- 运行脚本、样式、场景缺失时显示明确错误与重新加载按钮，禁止停留在无提示黑屏。
- 场景尺寸在完整 CSS 读取后重新测量，避免异步加载顺序影响相机及角色坐标。
- Android 原生启动底图使用 `drawable-nodpi`，避免高密度手机重复放大解码。WebView 首次绘制前保持品牌底图可见。

## 签到弹窗

- 使用真实组件与数据。禁止整张截图覆盖界面并以透明热区代替按钮。
- 弹窗保持 2:3 比例，尺寸同时受视口宽度、高度约束，保持安全边距，不拉伸背景。
- 日期、奖励、累计次数、补签状态均读取存档。日历偏移取当月 1 日星期，支持六行月份。
- 顶部、日历、奖励、操作和历史区独立排版；不得利用文字盒压缩掩盖溢出。按钮与文本不得互相覆盖。
- 关闭按钮独立可见，触控范围至少 44×44 CSS 像素。关闭后可重新打开；Escape 与 Android 返回键也能关闭。
- 自动签到与补签只发放一次；未来日期不可领取；累计奖励领取记录跨月保存。

## 每次交付检查

1. 在 320×568、360×640、390×844、430×932、1080×1920 检查弹窗完整显示、关闭、页签和点击。
2. 检查经营、工作台、订单、背包、穿搭日记、个人信息、社区、家装、排行榜的图片与 CSS 背景。
3. 检查延迟脚本、延迟样式和资源缺失时的启动表现。
4. 检查签到、补签、历史奖励、重复领取保护、跨月与重开持久化。
5. 包内逐文件校验、APK 签名校验、解包资源回归全部通过后交付。
6. 测试记录明确区分浏览器触控模拟与 Android 真机安装，不混写验收结论。
