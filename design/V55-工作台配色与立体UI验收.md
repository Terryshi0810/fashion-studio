# V55 工作台参考图配色与立体 UI 验收

日期：2026-11-04。独立 V55，保留 V54/V53 回退。本轮按用户提供的工作台图片调整视觉表现。

## 视觉调整

| 区域 | 调整 |
|---|---|
| 场景与面板 | 浅薰衣草背景，奶油白面板，圆角、内侧浅紫缝线与蜜桃色底边阴影 |
| 货币栏 | 浅色珠光胶囊，圆形立体图标底座、白色加号与梅紫数值；390px 及以上四种资源同排，较窄设备保留三栏 |
| 顾客订单 | 奶油色卡片、珊瑚粉描边、底边厚度；粉色“制作中”和金色“交付”区分状态；保留真实金币图标与奖励含义 |
| 合成棋盘 | 蜜桃粉托盘、乳白格子、薄高光描边与柔和底影 |
| 生产器状态 | 可生产格为薄荷绿；锁定生产器和未开放区域为浅紫；达标解锁与匹配选中保留金色提示 |
| 选中物品与工具 | 奶油底、蜜桃色虚线缝边、粉色立体仓储/剪刀按键；图谱、仓库、补给、上新使用统一矢量图标 |
| 底部导航 | 奶油白底、梅紫文字、图标柔和投影；选中工作台显示蜜桃色凸起底座 |
| 触摸反馈 | 高光、明暗及内阴影变化，按钮在正常文档流中保持占位，合成格不因按压位移 |

### 配色规范

| 用途 | 色值 |
|---|---|
| 奶油底色 | #FFFAF1 |
| 托盘蜜桃粉 | #FFD5D5 |
| 主要粉色 | #F78EB7 |
| 锁定浅紫 | #D8B7EB |
| 可交付金色 | #FFB326 |
| 主要文字梅紫 | #82416E |

颜色以参考图方向为准，按钮的文字、图标、边框、高光和底影共同表达层次。装饰缝线及星光由 CSS 绘制，不接收点击，不覆盖棋盘触控层。颜色不承担唯一的状态提示：锁图标、等级、按钮文案和可用状态继续保留。

## 适配与功能保护

- 保留 7×9 棋盘、现有订单、生产器解锁、材料、奖励、二合、体力、仓库和经营联动；V55 与 V54 的工坊核心文件 SHA256 相同。
- 面板增加内边距后，棋盘尺寸计算同步扣除边框和内边距，避免窄屏溢出和工具栏被压到导航下。
- 第一屏继续完整显示棋盘与底部工具；顶部货币数字允许省略号缩写，点击资源说明可查看完整余额。窄屏不强塞第四个资源栏。
- V55 使用独立存档键，首次读取 V54 后保留旧键。已接订单、教学阶段、物品和已启用生产器保留。

## 验收证据

- 23 项核心检查通过，复用现有合成、生产、交付、解锁、库存和新手路线回归。
- 23 项界面/触控检查通过，覆盖 320×568、360×640、360×780、390×844、430×932、1080×1920。主要工作台区块及顶部货币按钮无重叠、无横向溢出，底部操作同屏；锁定详情可开关。
- 触控模拟验证出料、同款二合、锁格拒绝落物、原地解锁、解锁后生产和刷新保存。
- V54→V55 的浏览器迁移通过：旧存档键未回写，已解锁列表、教学进度与订单保持。
- 七个模块入口冒烟检查通过，未发现脚本异常或图片缺失；此项仅验证入口和图像加载。
- 最终 APK 通过 v1/v2/v3 签名校验；390 项资源逐项对比大小及 SHA256，从签名 APK 解包后再次启动和检查工作台交互、资源。
- 未进行实体 Android 手机安装测试。界面和触摸证据来自 Chromium 移动视口及 CDP 触摸事件模拟。
