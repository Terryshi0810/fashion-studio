## 动态展示：必须区分的状态

**当前是自研加权网格动态预览，不是官方 Spine 播放。**

项目与用户截图中没有原版 Spine 导出的骨骼、图集和贴图资源。不能从一张截图直接还原原始骨骼、插槽、网格和动画时间线。因此本轮没有把图片的 CSS 平移或旋转冒充成 Spine。

本轮实际实现：

- 原创透明全身立绘 + 12×22 网格，528 个三角形。
- 呼吸、头部、发丝、袖饰/羽毛和裙摆使用不同权重产生局部变形。
- WebGL 渲染，目标更新频率 30fps，支持暂停和继续。
- 页面隐藏与弹窗覆盖时减少无意义重绘；离开展示页释放渲染对象。
- 系统减少动画设置下默认静态；设备未启用 WebGL 时明确显示静态兼容预览。
- 测试比较了服装自身的渲染像素，而不依赖背景星星是否闪烁。

### 接入真实 Spine 的下一步

需要提供原始导出资源：骨骼文件（JSON 或二进制）、图集、全部对应贴图，以及项目所用的 Spine 渲染器和动画名称。现有截图不是这些资源。

已预留 `FashionMeshPreview.registerSpineRenderer(renderer)` 和 `FashionSpineAssets` 配置入口。接口会把当前套装、画布、导出资源配置、暂停状态以及成功/失败回调交给真实渲染器；该渲染器应返回 `pause`、`resume`、`dispose`。接口本身**不会自动解码 Spine 文件，也没有打包官方运行时**。

`assets/lookbook-preview-rig.json` 只描述本轮自研网格预览，不是 Spine 导出文件。

## 收藏数据与奖励

- 实际内容为 **5 套套装、25 件服饰**，没有把截图中的 153/794 等总量伪造成已完成内容。
- 体验存档初始获得前 16 件，高定 5 部件默认未获得，额外礼服与饰品可继续点亮。
- 未获得服装可试穿查看；预览不会自动记为获得。
- 碎片点亮消耗 `星级×4` 个碎片；发现奖励为对应星级的钻石，仅一次。
- 集齐奖励：普通套装 5 钻石，高定套装 15 钻石，各一次。
- 本地评鉴奖励：集齐套装后可领取一次 100 金币 + 2 钻石，不冒充联网评委排名。
- 图鉴魅力为本地展示收藏属性，不改变原订单或正式评比赛公式。
- “体验集齐效果”必须二次确认，明确只修改本地演示收藏；不会向棋盘生成实物。
- 收藏、奖励、评分记录随现有本地存档保存。原棋盘实物不被图鉴操作消耗。

## 可编辑文件

- `lookbook-ui.js`：内容、三层页面、收藏与奖励交互。
- `lookbook.css`：参考风格 UI。
- `mesh-preview.js`：动态网格展示与真实 Spine 渲染器接口。
- `build-lookbook.js`：接入手机版并生成离线 V0.4。
- `mobile/`：接入后的完整手机版页面。
- `tests/lookbook-smoke.test.js`、`tests/lookbook-complete.test.js`：图鉴检查。

重建时运行 `node build-lookbook.js`。不要只运行旧的 `build-mobile.js` 后就交付，否则手机版源码会回到 V0.3 基础布局。单独保存的 V0.3 试玩仍保留用于比较。
