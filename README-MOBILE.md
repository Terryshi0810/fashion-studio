# 时光百货 · 手机试玩 V0.3

更新日期：2026-10-08。此版本以手机竖屏为主，不再使用桌面侧栏或双栏操作界面。

## 打开方式

使用手机浏览器打开 `fashion-studio-demo-mobile-v3.html`。全部美术和功能已嵌入单文件，打开后无需连接素材服务器，也无需安装游戏应用。

在电脑上打开同一文件，会以居中的手机框预览，不会重新展开为桌面版。

这是 HTML 手机浏览器试玩，不是 Android APK 或 iOS 安装包。

## 本轮手机适配

- 手机画面最大宽度 430px；在真实手机上占满可用宽度，在电脑和平板上保留竖屏手机框。
- 去除桌面侧栏；主地图、工作台、商店、评比赛、图鉴全部通过常驻底部导航进入。
- 顶部资源栏与底部导航保持固定，只滚动中间页面；支持安全区空间，避免底部手势区遮挡按钮。
- 调整资源数值、文字尺寸、购买按钮、标签和弹窗，减少横向溢出。
- 工作台按屏幕高度调整棋盘尺寸；375×667 竖屏中，棋盘和三种生成器能同时显示。
- 320×568 等短屏保留棋盘滚动，生成器前置并保持可操作，不强行缩成过小的格子。
- 保留触屏拖拽、两次轻点归位、合并反馈、订单、商店、装修、图鉴、赛事与本地存档。
- 弹窗改为手机尺寸的底部浮层，确认操作和关闭按钮均能在手机画面内操作。

## 试玩方法

1. 主地图点击“改造”，完成一个小心愿。
2. 工作台把 1 件 T 恤放到 9 件那摞上，叠满 10 件升阶。
3. 交付顾客订单，获取金币与经验。
4. 商店购买服饰或装饰；图鉴领取发现奖励；评比赛搭配三件服饰并提交。
5. 地图右上角的设置可导入/导出存档、重开和开启高阶体验。

初始为 LV12 体验存档。支付、广告、排行均为本地演示，尚未接入真实服务。

## 存档提醒

进度保存在当前浏览器。不同文件路径、浏览器和手机可能使用不同存储空间；如需从旧版迁移，请先在旧版导出存档，再在手机版导入。旧版 V0.2 单文件仍保留，未覆盖。

## 检查范围

- 手机尺寸：320×568、360×720、375×667、390×844、430×932。
- 电脑/平板预览：1440×1000、768×1024，仍保持手机框。
- 已检查五个页面、无横向溢出、离线图片、导航固定、短屏滚动和生成器可操作。
- 已用触屏事件检查合并、交单、购买、奖励防重复、评比、装修、六层开放与刷新恢复存档。
- 这些检查使用浏览器模拟手机尺寸；仍建议在目标安卓和 iOS 真机上验收浏览器工具栏、系统字体和触控体验。

## 项目源码

手机版源码在 `mobile/`，共用父目录的 `core.js` 与 `assets/`。`mobile-overrides.css` 为手机专用样式；`build-mobile.js` 可重新生成手机版源码和单文件。
